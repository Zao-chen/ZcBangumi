审计日期：2026-10-04（UTC；北京时间 2026-10-05）。范围是当前 GitHub Pages 静态网页版，不假设存在后端中转服务。

| 功能 | 实际来源 | 网页版处理 |
| --- | --- | --- |
| 发现页、放送日历、条目筛选、标签搜索 | `api.bgm.tv/v0` JSON | 保留；当前标签搜索已经迁移到公开 API，不能沿用旧版 HTML 标签抓取的判断 |
| 条目、角色、人物详情及其关联数据 | `api.bgm.tv/v0` JSON | 保留，包括章节、关联人物、作品与关系图 |
| Token 登录、收藏列表、评分、标签、章节进度、角色/人物收藏 | `api.bgm.tv/v0` 认证 JSON | 保留；公开 API 的预检允许 Authorization 和写请求。测试使用虚拟 Token 与模拟响应，不修改真实账号的收藏 |
| 萌娘百科及其他外站 | 直接网页链接 | 保留外链，不在网页里嵌入跨站 WebView 或抓取 HTML |
| 封面、头像、表情 | 直接图片 URL / 镜像资源域名 | 保留；共享图片组件在 Web 使用 HTML 图片元素渲染，不以 CanvasKit 的跨域像素读取方式加载；不附带自定义 Cookie / Token 请求头 |
| 外观、可用导航/标签排序、自动刷新、缓存与镜像 API 设置 | 浏览器本地存储 | 保留；不显示只适用于客户端的设置 |
| 诊断日志 | 网页内存 | 保留查看、复制、清空，并实现浏览器 Blob 下载；刷新后不保留日志 |

## 从内置网页功能中隐藏

| 功能 | 实际来源 / 平台依赖 | 原因与替代 |
| --- | --- | --- |
| 吐槽、目录的浏览和编辑 | `next.bgm.tv/p1` JSON | 实测响应没有 Access-Control-Allow-Origin；当前 `/v0/.../comments` 探测返回 404，不能假设可以直接替换。隐藏相关标签、加入目录按钮和个人目录入口；目录链接在原站打开 |
| 动态 | `next.bgm.tv/p1` JSON | 缺少跨域许可，网页版不请求、不显示入口 |
| 超展开、讨论详情、发帖、网页 Cookie 验证 | `bgm.tv` HTML / 表单 / Cookie | 缺少跨域许可，浏览器也不能代填跨站 Cookie；讨论、章节和日志链接交给原站 |
| Mikan 登录、订阅及资源操作 | 第三方站点会话与平台操作 | 保留完整客户端实现，隐藏网页入口 |
| HTTP/SOCKS 代理、客户端更新及安装、WebView 验证会话提取 | 原生网络或插件能力 | 不向浏览器展示无法完成的操作 |

可用功能集中在 `lib/services/platform_feature_support.dart`。UI 过滤之外，`WebNetworkConfig` 在网络发出前拒绝不可用的 P1 / 网页请求，避免无意义的 CORS 报错。Web Token 仅配置到公开 API 客户端，不配置到 P1 客户端。

## 已优化的网页体验

- 启动日志使用有容量限制的内存存储，客户端继续使用本地文件。
- 条目页面不再为了隐藏的吐槽标签额外发起请求；角色、人物和个人页移除相关不可用入口。旧设置只保留不可用标签时，安全回退到概述。
- 连接检查只检查网页实际使用的 API / 图片服务，不把 P1 / 网页 Cookie 服务误报为用户网络故障；镜像 Cookie 清理与原生验证说明不展示给网页用户。
- 网页提示改为说明可用功能，关闭后在当前浏览器记住；Token 登录明确说明本地保存和共享设备风险。
- CanvasKit 使用构建产物内的资源。中文常用字符与 Latin 字体本地打包，不依赖 Google 字体来显示基本界面。
- 实际浏览器发现 `lain.bgm.tv` 图片缺少 CORS 响应头；共享封面 / 头像组件改用浏览器 HTML 图片元素和浏览器缓存，客户端缓存逻辑不变。该模式不支持读取图片像素、截图部件或自定义鉴权请求头；不新增第三方图片代理。
- 页面启动前显示原生 HTML 加载状态；启动异常时提供刷新按钮，不停留在没有提示的白屏。
- 安装清单使用应用主题色和实际描述，允许横屏；剪贴板失败提供替代下载提示。
- 个人页和详情页的侧栏在高度不足时可以滚动；角色手机页的加载标签使用同一套平台能力过滤与控制器。
- 章节菜单不再显示加入目录；讨论操作明确跳转原站。条目和角色正文在 Web 暗色主题下使用主题前景色，不再固定为低对比度深灰。
- 删除未被应用读取的 `ZC_WEB_PROXY_BASE` 部署参数，避免误以为静态站点已经具备 CORS 中转。

字体来自 `@fontsource/noto-sans-sc@5.3.0` 的 Chinese Simplified / Latin 子集，许可证位于 `assets/fonts/OFL.txt`。其他文字或生僻字符仍可能触发字体回退，不声称覆盖所有语言。

## 不能靠前端代码补齐的部分

- 若需要网页内的目录、吐槽、动态或超展开，需要源站开放 CORS，或另外设计可信的服务端中转。代理涉及 Token / Cookie 的安全、限流和部署，不在静态站点中偷偷发送凭证或承诺已实现。
- 自定义域名 DNS、证书签发和 HTTPS 强制跳转仍需独立处理。代码构建通过不等于线上网站已经更新。
- 完整 OAuth 登录与任意深链接刷新恢复不是本次新增功能，当前保持现有 Token 登录和页面导航方式。
